# Загальний опис
  ESP32-yakymovich-A Опитує температуру, вологість та освітленність,
        перевіряє статус сенсорів та публікує температуру,
        вологість та освітленність у топіку
        iot-course/yakymovich/sensors
        раз на 10 сек. 
        При натисканні кнопки публікує команду "manual_read"
        у топіку
        iot-course/yakymovich/commands 
               

  ESP32-yakymovich-B Підписується на топіки
        iot-course/yakymovich/#
        із QoS = 1,  повідомлення обробляються callback-функцією onMessage
        із повідомлення береться тільки температура,функція керує світлодіодом, 
        змінюючи його стан у залежності від температури.
        При отриманні команди "manual_read" встановлює флаг прийому команди
        що його стан обробляється у фукнції loop() - виконується неблокуюче 
        блимання світлодіодом 3 рази       
        

  ESP32-A - ESP32-B
        Якщо пропадає конект із брокером або із WiFi
        виконується реконнект, максимум 3 спроби із інтервалом 5 секунд
        Усі повідомлення виводяться у термінал.
                  
        На жаль, запустити ESP32-A та ESP32-B у симуляторах
        одночасно не вийшло, комп старенький й став подвисати,  обидва
        ESP32 постійно губили коннект із брокером через WOKWI Wi-Fi.
        Тому зібрав ESP32-B (Subscriber) фізично: фоторезистора поки що немає,
        тому замість нього підключив змвнний резистор на 22К, та загрузив проект туди із           
        підключенням   до реального WiFi, а ESP32-A (Publisher) запустив у симуляторі. 
        Вийшло доволі прикольно. :) ESP32-B (Subscriber) реагував на натискання кнопки ESP32-A у симуляторі та 
        засвічував фізичний LED при підвищенні температури.
